# CozyEvent speed benchmark

Environment: Apple M4 (10 cores), Node v22.14.0 (V8 12.4.254.21-node.22), Darwin 25.5.0 arm64. Each library x scenario ran in its own process, 3 rounds (round-robin), benchmark.js maxTime 0.5s; the table shows the median run. Higher is better.

Generated by `node benchmark/run.js` on 2026-09-17T11:23:55.429Z.

Fairness: every library's own on/off/once/emit is called directly on the instance (no wrapper). Libraries without once (@braintree/event-emitter, @protobufjs/eventemitter, mitt, nanoevents) use the textbook userland once; nanoevents removes via the unbind function returned by on(). "same code" scenarios use closures of one function; "distinct" scenarios use different functions (polymorphic call sites). See benchmark/libs.js.
